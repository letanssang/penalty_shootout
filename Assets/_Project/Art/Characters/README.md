# Characters

**`XBot.fbx`** — Mixamo X Bot, T-pose, có skin (2 SkinnedMeshRenderer, 28 374 đỉnh).
Đang là Avatar gốc cho toàn bộ clip trong `Art/Animations/Mixamo/`.

`MixamoModelImport` tự dò FBX **đầu tiên** trong thư mục này. Thay model cầu thủ thật thì
bỏ file mới vào đây và xoá XBot — không phải sửa code. Model mới bắt buộc là Humanoid;
kiểm bằng menu **Eleven ▸ Art ▸ Report Mixamo Clips**, dòng `# Pose` phải ra T-pose.
